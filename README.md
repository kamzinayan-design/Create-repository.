# Create-repository

Рабочий репозиторий: конфигурации 1С, SQL-скрипты и AI-агенты.

## Структура

| Папка | Что внутри |
|-------|------------|
| `1c/` | Выгрузки конфигураций, обработки, отчёты, модули 1С |
| `sql/` | SQL-запросы, скрипты, миграции |
| `agents/` | AI-агенты: промпты, скрипты, настройки |
| `docs/` | Документация и заметки |

## Как пользоваться

1. Кладите файлы в нужную папку.
2. Сохраняйте изменения (commit) с понятным описанием, например: `sql: запрос остатков по складам`.
3. Пароли, ключи API и базы данных в репозиторий **не** добавляйте — для них есть `.gitignore`.
